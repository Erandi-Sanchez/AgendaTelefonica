# 🤖👾 Agenda Telefónica

Proyecto colaborativo para gestionar contactos, desarrollado en Java con IntelliJ IDEA.

##  Funcionalidades
- Añadir, buscar, eliminar y listar contactos.
- Validación de contactos duplicados.
- Orden alfabético automático.
